# La Mag

Лендинг бренда **La Mag** — кожаные чехлы для iPhone 17 Pro Max.
*Conceived in Italy. Made in Moscow.*

## Просмотр

Сайт опубликован через GitHub Pages:
👉 https://maybenekit.github.io/la-mag/

## Структура

- `index.html` — весь сайт одним файлом (стили, скрипты и изображения встроены)
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages

## Как обновить сайт

1. Отредактировать `index.html`
2. Закоммитить и запушить:

```bash
git add index.html
git commit -m "update site"
git push
```

Через 1–2 минуты изменения появятся по ссылке выше.
